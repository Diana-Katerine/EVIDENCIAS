# Ejecución

Esta carpeta fue creada para almacenar evidencias relacionadas con la ejecución de proyectos, pruebas y actividades prácticas.

Puedes agregar aquí:
- Informes de ejecución
- Resultados de pruebas
- Capturas de pantalla y registros
- Cualquier evidencia que muestre la ejecución de tus actividades

Estructura sugerida:
- Ejecución/Proyectos/
- Ejecución/Pruebas/
- Ejecución/Resultados/

Si quieres, puedo crear esta estructura de subcarpetas y plantillas para los archivos.
