# Evaluación

Esta carpeta fue creada para almacenar evidencias y documentos relacionados con la evaluación de proyectos, actividades y resultados.

Puedes agregar aquí:
- Informes de evaluación
- Rúbricas y criterios de calificación
- Resultados y análisis
- Evidencias y retroalimentación

Estructura sugerida:
- Evaluación/Rúbricas/
- Evaluación/Informes/
- Evaluación/Resultados/
- Evaluación/Evidencias/

Si quieres, puedo crear las subcarpetas sugeridas y añadir plantillas para informes o rúbricas.
