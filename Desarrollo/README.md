# Desarrollo

Esta carpeta fue creada para almacenar evidencias relacionadas con el desarrollo de proyectos, código fuente y documentación técnica.

Puedes agregar aquí:
- Repositorios o módulos de código
- Documentación técnica
- Pruebas y scripts
- Recursos y dependencias

Estructura sugerida:
- Desarrollo/Proyectos/
- Desarrollo/Código/
- Desarrollo/Documentación/
- Desarrollo/Tests/
- Desarrollo/Recursos/

Si quieres, puedo crear la estructura de subcarpetas y plantillas para archivos como README de proyecto o plantilla de pruebas.
